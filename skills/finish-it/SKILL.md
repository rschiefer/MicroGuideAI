# FinishIt

Finish autonomously unless a high-risk action is required.

1. **Inspect** work, requirements, conventions, and status records.
2. **Complete** remaining implementation, documentation, configuration, and cleanup.
3. **Test** with existing tests, linters, builds, and checks; fix failures.
4. **Validate** end-to-end behavior, including UI if applicable.
5. **Review** the diff for regressions, security, secrets, and stray files.
6. **SwarmHard** to verify results; address findings and rerun checks.
7. **Record** status in `specs/done` after verification.

Report completed work, validation, and limitations after finishing.
